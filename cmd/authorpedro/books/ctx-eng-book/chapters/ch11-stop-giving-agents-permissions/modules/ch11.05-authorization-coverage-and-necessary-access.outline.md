# Authorization Coverage and Necessary Access

## Argument
Authorization must measure not just whether access is allowed, but whether the retrieved context was both authorized AND necessary—preventing over-retrieval of data the model doesn't need.

## Why it matters
Current authorization models answer "can the agent access X?" but not "did the agent actually need X?" This gap leads to over-scoped context retrieval, violating least privilege and increasing attack surface.

## Beats

1. **The authorization-necessity gap** — evidence: kg-quality-metrics-notes
   - Traditional auth: authorized or not
   - Authorization Coverage: authorized AND necessary
   - Example: agent has access to 1000 customer records, retrieves all of them, but only needs 3 for the task
   - 100% authorized, ~0.3% necessary

2. **Least privilege in context retrieval** — evidence: ch11.01-least-privilege
   - Principle: retrieve the minimum context needed for the task
   - Not just access control, but retrieval control
   - The graph should route to only necessary sources

3. **Measuring authorization coverage** — evidence: kg-quality-metrics-notes
   - Authorization Coverage = (Authorized AND Necessary context) / Retrieved context
   - Measures: how much retrieved context was both permitted AND needed?
   - Aligns directly with least-privilege retrieval

4. **The over-retrieval problem** — evidence: GAP
   - Agents often retrieve more than needed "just in case"
   - Increases: token cost, latency, hallucination risk, data exposure
   - Need bounds on retrieval scope

5. **Techniques for necessary access** — evidence: GAP
   - Query-level authorization (what did you actually ask for?)
   - Result bounding (limit returned records)
   - On-demand vs preemptive retrieval
   - Competency-based context (only retrieve what this task type needs)

## Conclusion to reach
Authorization coverage extends access control to measure necessity. Context engineering must enforce that agents retrieve only what they need, not just what they can access. This requires measuring the intersection of authorized and necessary context.
