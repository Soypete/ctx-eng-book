# Provenance Coverage Metrics

## Argument
Context engineering must measure not just whether provenance exists, but what percentage of retrieved context includes source attribution, timestamps, confidence scores, and authorization metadata.

## Why it matters
Without provenance coverage metrics, teams cannot distinguish between context that can be trusted (has source attribution) and context that arrived without any metadata. This is critical for AI reliability—users need to know where information came from.

## Beats

1. **Provenance as prerequisite for trust** — evidence: ch10.03-provenance-and-derived-context
   - Provenance = source, owner, timestamp, confidence, authorization
   - Without provenance, model output cannot be traced back
   - Users cannot verify, cite, or audit the context

2. **Provenance coverage defined** — evidence: kg-quality-metrics-notes
   - Provenance Coverage = Context with provenance metadata / Total retrieved context
   - Example: retrieved 10KB of context, 3KB has source citation → 30% provenance coverage
   - Measures: source present, owner present, timestamp present, confidence present, authorization present

3. **The partial provenance problem** — evidence: GAP
   - Often get source but not timestamp
   - Or timestamp but not confidence
   - Need per-dimension coverage tracking

4. **Measuring in context assembly** — evidence: GAP
   - Each context component should carry provenance
   - Database query: include query time, table, row identifiers
   - API call: include response time, endpoint, status
   - Search result: include document source, score, crawl time

5. **Provenance degradation as incident** — evidence: GAP
   - When provenance coverage drops, AI outputs become less verifiable
   - Should alert when coverage < threshold
   - Track over time: is provenance improving or degrading?

## Conclusion to reach
Provenance coverage is a measurable quality metric for context engineering. Teams should instrument every context component to carry source, timestamp, confidence, and authorization metadata, then measure the percentage of retrieved context that includes these attributes.
