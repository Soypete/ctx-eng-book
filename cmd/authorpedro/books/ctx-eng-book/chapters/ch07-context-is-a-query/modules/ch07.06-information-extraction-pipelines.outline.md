# Information Extraction Pipelines

## Argument
Information extraction transforms unstructured text into structured context. IE is the bridge between raw data and queryable context—without it, unstructured text is noise; with it, becomes entities and relationships that can be assembled.

## Why it matters (reliability goal)
IE pipelines determine what entities and relationships exist in your context. Wrong extraction = wrong context. The pipeline from document to queryable entity must be engineered for precision, recall, and schema alignment.

## Beats

1. **IE as Context Transformation** — evidence: existing prose + ledger (IE as knowledge distillation)
   - IE is query engine in reverse: transforms text → structured data → queryable
   - Pipeline: input raw text → NER/relation/event extraction → structured output → storage → query
   - [IE with LLMs as knowledge distillation](research/knowledge-graphs/ie-ner.md): extracting and structuring knowledge from LLM training data into explicit knowledge graph

2. **Types of IE for Context** — evidence: existing prose + ledger (KG book ch07)
   - NER: people, orgs, locations, dates, products
   - Relation extraction: entity relationships (customer→purchased→product)
   - Event extraction: what happened, when (temporal context)
   - OpenIE: schema-free extraction for unknown/evolving domains
   - [Knowledge Graphs book Chapter 7](research/knowledge-graphs/07-informal-text-ie.md): multi-ontology approach for informal text (location, person, event ontologies simultaneously)

3. **KG Benefits Over Direct Database Queries** — evidence: ledger (Sequeda et al., 2023)
   - [GPT-4 on SQL: 16% accuracy → GPT-4 on Knowledge Graph: 54%](https://arxiv.org/2311.07509)
   - Structured relations enable better context retrieval

4. **LLM-Based Extraction** — evidence: ledger (LLMs can identify entities that don't match predefined categories)
   - LLMs can extract novel entity types using in-context learning
   - Zero-shot entity classification without training data
   - Risk: may hallucinate entity types outside ontology

5. **Reliability Questions** — evidence: GAP (needs research)
   - Precision vs recall trade-off
   - Schema mapping from extraction to domain
   - Temporal accuracy for events
   - Provenance tracking

## Conclusion to reach
IE pipelines feed the context assembly pipeline. Extraction quality, schema alignment, temporal accuracy, and provenance determine whether unstructured text becomes useful context or noise.
