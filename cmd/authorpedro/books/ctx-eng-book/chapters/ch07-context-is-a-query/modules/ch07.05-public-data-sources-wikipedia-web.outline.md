# Public Data Sources: Wikipedia and Web Indexing

## Argument
Wikipedia and web search indexes are underutilized public data sources that context engineers can leverage—their link-based structure mirrors file parsing and web crawling patterns that LLMs already understand.

## Why it matters
Most context engineering focuses on private data (databases, APIs, internal documents). But public data sources offer massive, pre-aggregated knowledge that requires no internal data infrastructure. Wikipedia alone contains millions of articles with sourced citations.

## Beats

1. **The public data gap** — evidence: GAP
   - Most RAG systems focus on private, proprietary data
   - Public data (Wikipedia, web indexes) is often ignored
   - These sources are already curated, linked, and often source-cited

2. **Wikipedia as structured context** — evidence: GAP
   - Wikipedia articles contain structured elements: infoboxes, sections, citations
   - Links between articles create a graph structure (HATEOAS-style)
   - LLM tools can navigate links the same way they parse file trees
   - Example: "give me all cities in France" → traverse France article → parse infobox → follow category links

3. **HATEOAS as parsing pattern** — evidence: user input (HATEOAS Wikipedia)
   - HATEOAS (Hypermedia as the Engine of Application State) = REST + links
   - Wikipedia's internal linking is essentially HATEOAS
   - LLMs are already trained on web pages - they understand link navigation
   - This is a pattern LLMs will see a lot - leverages existing training

4. **Google/web indexing as aggregator** — evidence: user input (Google new corpus)
   - Google's web index aggregates public data from across the web
   - Custom search engines can target specific domains
   - Can be used to retrieve public, source-cited information
   - Example: `site:wikipedia.org "topic"` for source-backed queries

5. **Practical patterns for public context** — evidence: GAP
   - Wikipedia API for structured retrieval
   - Google Custom Search for web-scoped queries
   - Combining: internal context (private) + public context (Wikipedia, web)
   - The public layer provides background knowledge the private data assumes

6. **Attribution and citation tracking** — evidence: GAP
   - Wikipedia includes citations - can trace back to primary sources
   - Google results show source domains
   - Important for reliability: know where public context came from

## Conclusion to reach
Context engineering should leverage public data sources as part of the context assembly pipeline. Wikipedia's link structure and source citations, combined with web search indexes, provide a pre-aggregated public knowledge layer that requires minimal infrastructure and leverages LLMs' existing understanding of web navigation patterns.
