# Sources of Context

## Argument
Context is not stored—context is assembled. Every piece of information a model sees arrives via a query. The "context window" is not a container filled from storage, it's a composition built from query results.

## Why it matters (reliability goal)
Context from distributed systems is the foundation of AI reliability. The quality of context depends entirely on the quality of the queries that retrieve it. Wrong filters, missing JOINs, wrong time windows—all create unreliable context.

## Beats

1. **The Storage Illusion** — evidence: existing prose
   - Engineers frame problem as storage: where to put context?
   - Wrong framing. Context is assembled from query results
   - Instead of "where do we store context," ask: which systems contribute, what queries retrieve it?

2. **Databases Are Query Engines** — evidence: existing prose + ledger (SPARQL, RDF standards)
   - SQL queries execute against specific schemas, apply filters, return finite rows
   - Model receives query result, not the table
   - Quality of context = quality of query
   - ACID transactions ensure coherent state

3. **APIs Are External Queries** — evidence: existing prose
   - REST/GraphQL queries to external systems
   - Network-distributed, externally governed
   - Failure modes: timeout, rate limit, schema change

4. **Documents Are Full-Text Queries** — evidence: existing prose
   - Full-text search scores relevance probabilistically
   - Query term determines documents retrieved
   - Volume problems: truncation strategies needed

5. **Search Indexes Are Inverted Queries** — evidence: existing prose + ledger (RAGGED)
   - Vector search, BM25 ranking
   - Opaque ranking vs explainable BM25
   - [Hsia et al., 2024](https://arxiv.org/abs/2403.09040) — reader robustness to noise is key determinant of RAG stability

6. **Event Streams Are Temporal Queries** — evidence: existing prose
   - Kafka/Pulsar return sequences over time, not snapshots
   - Consistency challenges: missed events, offset reset
   - Model receives temporal slice—completeness depends on stream architecture

7. **Lakehouses Are Analytical Queries** — evidence: existing prose
   - Aggregate statistics, not raw records
   - Latency may be seconds to minutes
   - Data may be stale (hourly/daily updates)

## Conclusion to reach
Context engineering means engineering queries. The systems that produce reliable AI are not the ones with the largest context windows—they're the ones with the best query pipelines.
