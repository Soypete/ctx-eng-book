# Regression and Scenario Testing

## Argument
Regression testing for AI means comparing outputs across versions to distinguish meaningful changes from acceptable variance. Build regression suites from production failures.

## Why it matters (reliability goal)
Tie to Pragmatics pillar: behavioral regression tracks whether your system's pragmatics (instructions, examples, context) are working correctly over time.

## Beats

1. **Regression Testing—Comparing Outputs Across Versions**
   - Same input → current version vs. previous version
   - Challenge: some difference is expected (AI outputs vary)
   - Output comparison with allowed variation: define invariants (same structured data, same key facts, same tool calls)
   - Behavioral regression: compare outcomes, not outputs (did user get correct answer?)

2. **Build Regression Suites from Production Failures**
   - Every bug that reaches users → test case in regression suite
   - Regression suite becomes living record of failure modes
   - Run before every deployment to prove you're not reintroducing known problems

## Conclusion to reach
The reader should believe that regression testing is how you answer "are we improving or degrading?"—by building a suite from every failure you've suffered.
