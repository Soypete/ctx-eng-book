# Pipes, Files, and Explicit Interfaces

## Argument
Context assembly should work like UNIX pipes—stages transform or enrich context, passing results to the next. Context stores should expose file-like interfaces—stable abstractions that different backends can implement.

## Why it matters (reliability goal)
Enable composition through standardized interfaces; allow swappable implementations without rewriting retrieval logic.

## Beats

1. **Pipes: Context as Data Flow** — evidence: DSPy declarative computational graphs [Khattab et al., 2023](https://arxiv.org/abs/2310.01428)
   - Each stage knows only input and output; pipeline orchestrates without stage awareness
   - Retrieval → Ranking → Formatter → Model; each swappable independently
   - Modules composed through standardized interfaces, compiler optimizes whole pipeline

2. **Files: Stable Interfaces** — evidence: OKF as portable knowledge-artifact format [GoogleCloudPlatform, 2026](research/open-knowledge-format-notes.md)
   - Uniform interface (read, write, seek, get metadata) regardless of backend
   - Retrieval system exposes file-like interface: open(query) → read() → close()
   - Backend could be vector DB, knowledge graph, full-text search, SQL with RLS

3. **Context as Mounted State** — evidence: format provides knowledge, platform provides trust [GoogleCloudPlatform, 2026](research/open-knowledge-format-notes.md)
   - Different stores contribute context through file-like interface, mounted at specific paths
   - Model operates on assembled context, authorization at mount points
   - Composable retrieval: add new sources by mounting, not rewriting

4. **Progressive Disclosure** — evidence: OKF navigation pattern [GoogleCloudPlatform, 2026](research/open-knowledge-format-notes.md)
   - Root index → Domain index → Concept summary → Full concept
   - Agents navigate instead of loading entire corpus

## Conclusion to reach
The reader should believe that context flows through stages like UNIX pipes, each with stable file-like interfaces, mounted into a unified namespace.
