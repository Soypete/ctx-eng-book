# Agent Workspaces and Secret Management

## Argument
An agent needs a working directory—a workspace with scoped context, memory, tools, secrets, output, and scratch space. UNIX-style permissions (read, write, execute) map to capability-based access control.

## Why it matters (reliability goal)
Contain failures; enforce permissions at filesystem level; prevent credential leakage.

## Beats

1. **Agent Workspaces** — evidence: capability-based access for AI agents [Brandstetter et al., 2024](https://arxiv.org/abs/2412.10891)
   - /workspace/context/, /memory/, /tools/, /secrets/, /output/, /scratch/
   - Each agent gets isolated workspace, resources scoped, failures contained

2. **Scoped Filesystem Access** — evidence: off-host identity-bound authorization [Kodathala, 2026](https://arxiv.org/abs/2607.05518)
   - Data access scopes, retrieval boundaries, tool permissions
   - System-level enforcement, not application-level checks

3. **Capability-Based Access Control** — evidence: Brandstetter et al. [2024](https://arxiv.org/abs/2412.10891)
   - Read capability → retrieval capability
   - Write capability → tool execution capability
   - Execute capability → memory access capability

4. **Secret Management** — evidence: aiAuthZ off-host authorization [Kodathala, 2026](https://arxiv.org/abs/2607.05518)
   - The most expensive model refused only half of attacks despite twentyfold price spread
   - Gateway prevents deceived model from acting beyond verified user's authority
   - Scoped credentials, token isolation, permission enforcement

5. **Cryptographic Confinement** — evidence: Governed Individuation [Qin et al., 2026](https://arxiv.org/abs/2607.04613)
   - Autonomous agents increasingly learn while deployed; confinement guaranteed as execution architecture invariant
   - Secrets mounted into workspace, never in context window; execution layer uses secrets, not model

## Conclusion to reach
The reader should believe that agent workspaces with capability-based access and filesystem-level secret management provide the isolation needed for reliable AI systems.
