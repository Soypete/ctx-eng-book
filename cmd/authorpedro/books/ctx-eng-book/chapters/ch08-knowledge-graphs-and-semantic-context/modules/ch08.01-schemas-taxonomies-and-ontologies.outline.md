# Schemas, Taxonomies, and Ontologies

## Argument
Knowledge graphs answer "how do we represent meaning instead of text?" They provide deterministic, explicit relationships that models can rely on—shifting from hoping the model infers to encoding relationships explicitly.

## Why it matters (reliability goal)
Tie to Semantics pillar: represent meaning as structure. LLMs understand language probabilistically; knowledge graphs make relationships explicit, auditable, and governable.

## Beats

1. **What the Graph Represents** — evidence: ledger (RDF as standard data interchange model - W3C)
   - Identity: unique identifiers eliminate ambiguity
   - Type: typed edges (supplies vs manufactures)
   - Constraints: enforce valid relationships
   - Provenance: track source of every triple

2. **Reasoning Shifts to the Model** — evidence: ledger (Graph as semantic router - kg-quality-metrics-notes)
   - Classical KGs: reasoning in the graph (OWL reasoners)
   - Modern KGs with LLMs: reasoning in the model, graph provides structure
   - Graph is retrieval substrate, model is interpretation engine

3. **KG-Shaped Retrieval** — evidence: ledger (Hybrid Retrieval - 49.1 P@5 with graph)
   - GBrain: typed edges, schema packs, graph traversal
   - Benchmark: +31 P@5 points over vector-only RAG
   - Graph structure for retrieval reliability, LLM for interpretation

4. **Ontologies as Guardrails** — evidence: ledger (Ontologies foundational for RE - relation-extraction)
   - Ontology guides extraction AND validates output
   - Define valid entities/relations, extract only what ontology allows
   - Validate every extraction against constraints before model sees it

5. **Multi-Ontology and Open-World** — evidence: ledger (Wikidata - public KG)
   - Real-world data spans multiple ontologies (Geo, FOAF, Events, Products, Temporal)
   - Public KGs for bootstrapping: Wikidata, DBpedia, YAGO, schema.org
   - Hybrid: public for classification, custom for constraints

6. **Granularity Matters** — evidence: ledger (KG Quality Dimensions - Zaveri et al., 2015)
   - Simple triples lose information (what, when)
   - N-ary tuples preserve more: (John, gave, Mary, book, yesterday)
   - Enables temporal reasoning, attribution, quantities, polarity

## Conclusion to reach
The reader should believe that knowledge graphs transform "guessed inference" into "engineered meaning"—explicit relationships that are deterministic, auditable, and governable.
