# Computational Pragmatics

## Argument
The most common AI failure isn't missing information — it's speech act interpretation failure. The model doesn't understand what the user wants DONE with the information provided.

## Why it matters (reliability goal)
Tie to Pragmatics pillar: align model behavior with user intent. Without explicit pragmatic context (goals, constraints, scope), even correct semantic information produces wrong actions.

## Beats

1. **Speech Act Interpretation** — evidence: [Jurafsky computational pragmatics](research/computational-pragmatics-notes.md), [ReAct paper](https://arxiv.org/abs/2210.03629)
   - Four inferential problems: reference resolution, speech act, discourse coherence, abduction
   - Speech act has highest production impact — wrong tool calls, incorrect actions
   - ReAct, chain-of-thought, plan modes: add structure to help model extract actual intent

2. **"Doing the Inference Work"** — evidence: [DSPy pragmatics injection](research/dspy-notes.md)
   - Instead of vague prompts, explicitly specify desired outcome and constraints
   - DSPy formalizes: "do this, and I want this result"

3. **Indexicality Problem** — evidence: [Pragmatics as bridge](research/wordnet-anchor-text-notes.md)
   - "The data", "my files" — same phrase, different referents in different contexts
   - Without explicit scoping → wrong data access → plausible but incorrect answers

## Conclusion to reach
The reader should believe that pragmatic context (what to do, not just what something is) is the missing piece that transforms semantic correctness into actionable reliability.
