# Missing and Incorrect Information

## Argument
Every AI failure is fundamentally a context failure—the model made the best decision it could with the information it had, and that information was missing, incorrect, or unconstrained.

## Why it matters (reliability goal)
Tie to Pragmatics pillar: align model behavior with user intent. Without correct, complete context, alignment is impossible.

## Beats

1. **The Demo-to-Production Gap** — evidence: existing prose (the demo constrained outcomes, production doesn't)
   - Establish that demos limit scope; real-world has unbounded inputs

2. **Hallucinations Are Missing Context** — evidence: existing prose + ledger (LLM refusal under attack - model follows context even when context is wrong)
   - A hallucination is a model filling gaps with its prior — the gap is missing context
   - Provide all three: semantics, pragmatics, and data → minimum error

3. **Wrong Tool Calls Are Missing Context** — evidence: ledger (dangerous retrieval, context-to-execution integrity)
   - Agents retrieve without direction → incorrect assumptions proliferate
   - Auto-generated tools without scoped purposes → selection failures

## Conclusion to reach
The reader should believe that AI failures aren't mysterious—they're traceable to missing or incorrect information. The fix isn't better models, it's better context.
