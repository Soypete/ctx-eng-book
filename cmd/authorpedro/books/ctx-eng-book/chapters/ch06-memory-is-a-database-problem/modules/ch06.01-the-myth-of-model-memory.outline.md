# The Myth of Model Memory

## Argument
Memory in AI systems is database engineering, not model capability. Transformers have no persistent state—only retrieval from external systems you build.

## Why it matters (reliability goal)
Tie to Pragmatics pillar: if you don't know where state lives, you can't debug failures. Memory failures are retrieval failures.
