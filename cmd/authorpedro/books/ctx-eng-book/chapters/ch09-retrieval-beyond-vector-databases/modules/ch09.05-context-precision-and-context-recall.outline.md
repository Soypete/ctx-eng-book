# Context Precision and Context Recall

## Argument
Context engineering needs metrics beyond traditional information retrieval: context precision measures how much retrieved context is useful, while context recall measures whether retrieval missed important information.

## Why it matters
IR precision/recall measures documents. Context precision/recall measures the actual useful information within those documents. A system can have high IR precision but low context precision if it retrieves verbose documents containing little useful context.

## Beats

1. **The precision overloaded problem** — evidence: kg-quality-metrics-notes
   - IR precision = (relevant docs) / (retrieved docs)
   - Wikidata precision = temporal granularity (year, month, day)
   - KG ontology precision = concept granularity (Employee vs Faculty Member)
   - Context precision = (useful context) / (retrieved context) — different metric

2. **Context precision defined** — evidence: kg-quality-metrics-notes
   - Context Precision = Useful Context / Retrieved Context
   - Too much irrelevant context increases: cost, latency, attention competition, hallucination risk
   - Example: retrieved 10KB of context, only 2KB useful → 20% context precision

3. **Context recall defined** — evidence: kg-quality-metrics-notes
   - Context Recall = Relevant Context Retrieved / Relevant Context Available
   - Hard to measure because denominator (relevant context available) is rarely known
   - Proxy: competency questions, ground truth datasets

4. **The context efficiency trade-off** — evidence: ch14.02-retrieval-tool-and-latency-costs
   - More context = higher precision risk, higher recall potential
   - Need to balance: retrieve enough for recall, not so much that precision drops
   - Token budget constraints force this trade-off

5. **Measuring in production** — evidence: GAP
   - Token-level precision tracking (useful tokens / total tokens)
   - Relevance feedback for recall estimation
   - Model-provided "used context" signals

## Conclusion to reach
Context precision and context recall are essential metrics for context engineering that go beyond traditional IR metrics. Teams should measure useful context vs retrieved context, track token-level precision, and estimate recall through competency questions.
