# Graph and Hybrid Retrieval

## Argument
Graph traversal retrieves connected context that keyword and vector search cannot express—dependency relationships, temporal sequences, organizational hierarchies. Hybrid retrieval combines multiple primitives into a single pipeline.

## Why it matters
"Server outages affecting payment processing" requires traversing from payment service to dependencies to servers to outages. This is structural, not semantic. Vector search cannot express dependency relationships. Hybrid retrieval is the difference between random performance (18 P@5) and production-ready (49.1 P@5).

## Beats

1. **Graph Traversal for Connected Context** — evidence: existing prose
   - Knowledge graph representing organizational structure, asset hierarchy, causal dependencies
   - Traverse from starting nodes along relationship edges
   - Temporal reasoning: "what happened after the deployment?"

2. **Graph for Agentic Systems** — evidence: kg-quality-metrics-notes (line 658-664)
   - Agents act on structured state: task graphs, dependency chains, authorization hierarchies
   - "What can I do?" = traverse permission graph
   - "What's the current task state?" = traverse task dependency graph

3. **Hybrid Retrieval Performance** — evidence: hybrid-retrieval-architectures (line 67-73)
   - Four-strategy hybrid: vector + BM25 + RRF + graph = 49.1 P@5
   - Each component alone ~18 P@5
   - Graph traversal contributes +31 points

4. **Hybrid Architecture Components** — evidence: existing prose
   - Query parsing: structured filters, keywords, semantic components
   - Structured query, keyword search, vector search, graph traversal, reranking
   - Each stage optional based on query type

5. **Context-Bench Benchmark** — evidence: Letta Context-Bench
   - Tests LLM file operations, relationship tracing, long-horizon retrieval
   - Best model (Claude Sonnet 4.5) scores 74%
   - Gap signals context engineering is distinct competency

## Conclusion to reach
Build hybrid retrieval that combines structured queries, keyword search, vector search, and graph traversal. The architecture chooses the primitive based on what's being retrieved.
