# Semantic and Retrieval Infrastructure

## Argument
Retrieval is where most systems fail, and where most engineering effort should go. The retrieval pipeline has four stages—query understanding, search execution, ranking, filtering—and each is a potential failure point.

## Why it matters (reliability goal)
Tie to Pragmatics pillar: the model can only generate good output if retrieval provides good context. Poor retrieval = poor responses, regardless of model quality.

## Beats

1. **Query Understanding** — evidence: existing prose
   - Parse user question into retrieval query
   - Keyword extraction, embedding generation, structured query
   - Extract search terms and filters from natural language

2. **Search Execution** — evidence: ledger (Context Precision = Useful Context / Retrieved Context; too much irrelevant context increases cost, latency, attention competition, hallucination risk [arXiv:2409.16041](https://arxiv.org/abs/2409.16041))
   - Query multiple stores in parallel
   - Each store returns results in its own format
   - Normalization layer required

3. **Ranking** — evidence: ledger (reader robustness to noise is key determinant of RAG stability; some readers benefit from increased retrieval depth, others degrade due to sensitivity to distracting content [arXiv:2407.01376](https://arxiv.org/abs/2407.01376))
   - Score and reorder results from different stores
   - Combine signals: BM25, path distance, recency
   - Cross-encoder reranking improves quality

4. **Filtering** — evidence: ledger (an agent should traverse the graph to discover: where information lives, who owns it, authorization requirements, retrieval method, semantic relationships; the graph routes retrieval [arXiv:2307.03367](https://arxiv.org/abs/2307.03367))
   - Apply authorization boundaries
   - Remove results user can't access
   - Integrated into pipeline, not post-processing

## Conclusion to reach
The reader should believe that retrieval pipeline quality determines system quality, and that each stage requires careful engineering and measurement.
