# Prompt, Retrieval, and Tool Lineage Notes

## ch16.02 — Sources queued for review

- Peter Buneman, Sanjeev Khanna, and Wang-Chiew Tan (2001). *Why and Where: A Characterization of Data Provenance*. International Conference on Database Theory. https://www.pure.ed.ac.uk/ws/files/16509989/Why_and_Where_A_Characterization_of_Data_Provenance.pdf
  - **Why it matters here:** distinguishes why-provenance from where-provenance, supporting separate records for source influence and source location.
- James Cheney, Laura Chiticariu, and Wang-Chiew Tan (2009). *Provenance in Databases: Why, How, and Where*. Foundations and Trends in Databases. https://doi.org/10.1561/1900000006
  - **Why it matters here:** surveys provenance semantics and capture/query techniques, supporting lineage as more than a collection of identifiers.
- W3C (2013). *PROV-O: The PROV Ontology*. W3C Recommendation. https://www.w3.org/TR/prov-o/
  - **Why it matters here:** provides an interoperable vocabulary for entities, activities, agents, and provenance relations that can be specialized for application lineage.
- Yining She, Yiliang Liang, and Eunsuk Kang (2026). *Safeguarding LLM Agents from Misalignment through Provenance Analysis*. arXiv. https://arxiv.org/abs/2607.01236
  - **Why it matters here:** directly studies whether proposed tool calls are supported by traceable evidence before execution, matching the proposal-versus-effect boundary.
