# Interface Envelopes and Provenance Notes

## ch12.02 — Sources queued for review

- W3C Provenance Working Group (2013). *PROV-DM: The PROV Data Model*. W3C Recommendation. https://www.w3.org/TR/prov-dm/
  - **Why it matters here:** defines a provenance model and constraints for describing how entities, activities, and agents relate, supporting provenance-bearing context envelopes.
- Apostolos Destounis, Georgios S. Paschos, and Iordanis Koutsopoulos (2016). *Streaming Big Data meets Backpressure in Distributed Network Computation*. IEEE INFOCOM 2016. https://arxiv.org/abs/1601.03876
  - **Why it matters here:** studies query streams whose limits arise from both communication and computation capacity, supporting explicit backpressure and deadline behavior across stages.
- Ioannis Chatzigiannakis, Sotiris Nikoletseas, and Paul G. Spirakis (2004). *Distributed Computation and Communication in Wireless Sensor Networks*. Theoretical Computer Science, 323(1–3), 175–197. https://doi.org/10.1016/j.tcs.2004.04.012
  - **Why it matters here:** analyzes computation and communication as coupled distributed resources, supporting the module's warning that a transport abstraction cannot erase operational guarantees.
