# Context Precision and Context Recall

## Argument
Retrieval evaluation requires explicit judgment units and bounded denominators; context precision is a proposed evidence-unit view, not a universal composite quality equation.

## Reliability goal
Locate failures across retrieval, assembly, authorization, evidence use, and outcomes without collapsing incompatible metrics.

## Sequence
1. Define conventional judged metrics. 2. qualify context precision. 3. bound recall. 4. evaluate budget tradeoffs. 5. build an end-to-end harness. 6. use ablation and failure injection.
