# Context Precision and Context Recall

## Argument
Retrieval evaluation requires explicit judgment units and bounded denominators; context precision is a proposed evidence-unit view, not a universal composite quality equation.

## Reliability goal
Locate failures across retrieval, assembly, authorization, evidence use, and outcomes without collapsing incompatible metrics.

## Sequence
1. Define conventional judged metrics and show the evaluation boundary in Mermaid. 2. Connect the curriculum's labelled cases, hit rate/MRR ladder, and faithfulness checks. 3. Qualify context precision. 4. Bound recall. 5. Evaluate budget tradeoffs. 6. Build an end-to-end harness. 7. Use ablation and failure injection.
