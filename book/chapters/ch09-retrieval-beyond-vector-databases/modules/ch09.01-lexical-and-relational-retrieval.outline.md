# Lexical and Relational Retrieval

## Argument
Reliable retrieval classifies the information need before selecting lexical,
dense, graph, or hybrid candidate generation, or an authoritative keyed or
relational lookup. Candidate reliability depends on authority, semantics,
scope, freshness, and evaluation.

## Reliability goal
Prevent similarity ranking from substituting for authoritative state and prevent BM25 from being mistaken for exact lookup.

## Sequence
1. Classify query types. 2. Explain lexical ranking and analysis. 3. Use scoped relational state for authority. 4. Combine primitives only for mixed tasks. 5. Evaluate each boundary separately.

## Example
Versioned tenant-scoped entitlement query.
