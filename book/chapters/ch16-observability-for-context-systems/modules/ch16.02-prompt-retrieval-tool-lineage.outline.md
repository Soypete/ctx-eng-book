# Prompt, Retrieval, and Tool Lineage

## Argument
Lineage connects versioned inputs, selection decisions, proposals, effects, and outputs without requiring unsafe duplication of content.

## Beats
1. Record prompt rendering and admitted-context manifests.
2. Separate retrieval candidates, authorization, ranking, and admission outcomes.
3. Follow tool proposals through validation, authorization, dispatch, receipts, and state.
4. Test reconstruction through incident drills and isolated replay.

## Reliability takeaway
Lineage earns its cost when an investigator can reproduce the relevant boundary failure.
