# State, Outcome, Cost, and Latency Observability

## Argument
Aggregate source, semantic, policy, state, outcome, cost, and tail-latency signals complement traces and expose systemic regressions.

## Beats
1. Observe source freshness, semantic coverage, policy decisions, and attempted and committed state transitions.
2. Keep metrics low-cardinality and link to traces.
3. Attribute lifecycle cost to task and terminal outcome.
4. Measure the critical path, tail, sampling, and telemetry loss.
5. Test hypotheses through controlled evaluation.

## Reliability takeaway
Telemetry is evidence for diagnosis and evaluation, not causal proof or the domain source of truth.
