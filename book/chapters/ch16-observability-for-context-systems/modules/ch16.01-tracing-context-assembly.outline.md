# Tracing the Context-to-Outcome Pipeline

## Argument
Traces make Lexicon, semantic, pragmatic, model, and outcome boundaries reconstructable; they do not expose a model's faithful internal cause.

## Beats
1. Trace sources and authority, semantic transformations, assembly, model inputs, policy decisions, effects, state, and outcomes in a nested run tree.
2. Use parent-child spans and links across asynchronous work.
3. Treat the retrieve/generate/check example as a teaching asset, not a production implementation.
4. Use OpenTelemetry as interoperable plumbing, not the context-observability category or domain record.
5. Protect content, govern sampling, and debug with competing hypotheses.

## Reliability takeaway
Observability narrows the failing boundary and supplies evidence for controlled diagnosis.
