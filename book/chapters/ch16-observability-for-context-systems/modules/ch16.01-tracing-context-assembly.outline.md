# Tracing Context Assembly

## Argument
Traces make context-system operations reconstructable; they do not expose a model's faithful internal cause.

## Beats
1. Trace planning, retrieval, assembly, model, tool, state, and outcome boundaries.
2. Use parent-child spans and links across asynchronous work.
3. Use OpenTelemetry as interoperable telemetry plumbing, not the domain record.
4. Protect content, govern sampling, and debug with competing hypotheses.

## Reliability takeaway
Observability narrows the failing boundary and supplies evidence for controlled diagnosis.
