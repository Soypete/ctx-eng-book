# Missing State and Constraints

## Argument
Loops, permission violations, and cost overruns often expose missing workflow state, boundaries, budgets, or exit criteria; reliable systems enforce those constraints outside the model.

## Why it matters (reliability goal)
Tie to State pillar: maintain continuity across interactions. Tie to Governance pillar: prevent unauthorized access.

## Beats

1. **Agent Loops Are Missing Exit Criteria** — evidence: existing prose
   - Agents don't know when to stop because success criteria weren't in context
   - Column name misspellings, multi-step dependencies → workaround loops

2. **Permission Failures Are Unconstrained Context** — evidence: ledger (prompt injection framework, capability-based access)
   - Prompt-based permissions inherit user credentials → prompt injection vulnerability
   - Fix: structural authorization, not prompt instructions

3. **Cost Overruns Are Unmeasured Context** — evidence: ledger (context precision, context cost of composition)
   - No budget controls → unlimited token consumption, redundant calls
   - Compaction failures: how to shorten context without losing relevance

## Conclusion to reach
The reader should believe that agents need structural constraints (state, permissions, budgets) encoded in the system, not in prompts.
