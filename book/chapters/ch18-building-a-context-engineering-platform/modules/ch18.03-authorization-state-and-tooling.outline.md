# Authorization, State, and Tooling

## Argument
Trusted software binds authority, durable state, and typed effects around model proposals.

## Durable state and recovery flow

Mermaid flow from chat projection through durable workflow loading, lease acquisition, authorization, idempotent dispatch, receipt persistence, state commit, and worker replacement.

## Beats
1. Enforce at query and commit boundaries; keep credentials outside context.
2. Separate the transcript projection from the durable workflow record.
3. Resume versioned state after rolling deploys or worker replacement.
4. Give tools narrow contracts and classified outcomes.
5. Reconcile ambiguous effects before retry.
