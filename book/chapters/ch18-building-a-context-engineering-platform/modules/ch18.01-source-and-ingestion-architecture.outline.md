# Source and Ingestion Architecture

## Argument
A context platform is a set of enforceable contracts connecting authoritative sources, rebuildable derived state, decisions, and outcomes.

## Beats
1. Follow evidence through ingestion, retrieval, action, and evaluation.
2. Version provenance, policy, correction, deletion, and processing outcomes.
3. Choose stores by invariant and query rather than vendor category.

## Reliability takeaway
The platform boundary is the contract; use the smallest topology that meets failure requirements.
