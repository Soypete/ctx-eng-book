# Knowledge Extraction Methods

## Argument

Extraction method selection is a field-level empirical decision; reliable systems cascade parsers, classifiers, open extraction, and language models behind one validation contract.

## Reliability goal

Avoid universal precision/recall and cost claims, and choose methods using representative errors and downstream consequences.

## Sequence

1. Select per field and document class.
2. Route methods through a common validation contract in a Mermaid flow.
3. State each method's contribution and common failure.
4. Connect the curriculum's three graph construction methods and schema comparison to method selection.
5. Build a routed cascade.
6. Evaluate evidence support, identity, constraints, abstention, cost, and task outcomes.
