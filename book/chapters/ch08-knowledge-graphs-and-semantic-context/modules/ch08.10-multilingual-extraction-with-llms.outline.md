# Multilingual Extraction Is an Evaluation Problem

## Argument

Multilingual models provide a shared extraction baseline, but production reliability requires stable identifiers, preserved source language, per-slice evaluation, and explicit fallback.

## Reliability goal

Prevent aggregate multilingual claims from hiding degraded extraction, identity resolution, normalization, or policy behavior for particular languages.

## Sequence

1. Separate shared deployment from uniform quality.
2. Make the per-language route, threshold, fallback, and monitoring loop explicit in Mermaid.
3. Keep identifiers independent from multilingual labels while preserving source text.
4. Select direct extraction, specialization, translation, or review empirically.
5. Connect RAGAS and DeepEval artifacts to stratified multilingual evaluation without claiming the curriculum is a multilingual benchmark.
6. Evaluate language, script, code-switch, field, and consequence slices.
7. Monitor drift and corrections by extraction route and version.

## Corrections

Removed unsupported percentage gaps, universal code-switch claims, language-independent relation claims, and assertions that one LLM dominates language-specific systems in cost and quality.
