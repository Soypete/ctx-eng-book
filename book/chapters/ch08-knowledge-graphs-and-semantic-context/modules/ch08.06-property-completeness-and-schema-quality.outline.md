# Property Completeness and Schema Quality

## Argument

Property completeness is meaningful only against versioned, applicable task requirements and must preserve absent, unknown, inapplicable, withheld, stale, and invalid states.

## Reliability goal

Prevent fill-rate optimization from inventing values, widening disclosure, or rewarding an ontology that is detailed but unusable.

## Sequence

1. Define applicable-property completeness and show its denominator decision in Mermaid.
2. Connect requirement-specific completeness to the curriculum's versioned RAGAS test set and datasheet.
3. Preserve distinct missingness states.
4. Evaluate definitions, constraints, authority, evolution, and competency questions.
5. Govern composition across domain models.
6. Measure by task and consequence.

## Evidence status

The formulation is a proposed operational metric informed by linked-data completeness work; downstream predictive value remains an evaluation question.
