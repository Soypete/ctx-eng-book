# Personalization as Governed Retrieval

## Argument
Personalization is governed data access: it binds authenticated identity, source authority, semantic status, and purpose to enforceable retrieval decisions before user-specific state becomes context. It applies to agents and non-agentic language systems.

## Reliability goal
Prevent prompts or model-generated attributes from acting as authorization.

## Sequence
1. Establish personalization as governed data access. 2. Connect the curriculum's episodic, semantic, and working memory flow in Mermaid. 3. Map identity and source authority to Lexicon, meaning and derivation to Semantics, and permitted use to Pragmatics. 4. Separate policy decision and enforcement. 5. Present ABAC as one model. 6. Govern purposes and derivation; test identity and revocation failures.
