# Provenance Coverage Metrics

## Argument
Provenance coverage measures conformance to item-type evidence contracts by item and field; it does not establish truth or authorization correctness.

## Reliability goal
Detect lineage gaps needed for audit, replay, correction, deletion, and claim support.

## Sequence
1. Define required evidence by item type. 2. measure item and field coverage. 3. add reviewed claim-support coverage. 4. validate in assembly. 5. alert by consequence and test lifecycle.

## Corrections
Removed byte-based coverage, universal confidence requirements, and claims that web search or developer code automatically supplies trust.

## Readiness
Edited; proposed operational metric is narrowly defined.
