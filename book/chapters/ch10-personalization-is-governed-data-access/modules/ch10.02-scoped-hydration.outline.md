# Scoped Hydration Across Stores

## Argument
Scoped hydration coordinates one authenticated task across heterogeneous enforcement semantics: Lexicon controls eligible sources, Semantics controls valid combinations and interpretations, and Pragmatics controls permitted use. Indexes, paths, caches, or service credentials must not weaken policy.

## Reliability goal
Prevent unauthorized data from influencing candidate generation or reaching model context.

## Sequence
1. Require adapter capability contracts. 2. Push policy into candidate generation. 3. Govern identities, paths, and caches. 4. Preserve denial semantics across the spine. 5. Test alternate access paths.
