# Scoped Hydration Across Stores

## Argument
Scoped hydration coordinates one authenticated task across heterogeneous enforcement semantics without allowing indexes, paths, caches, or service credentials to weaken policy.

## Reliability goal
Prevent unauthorized data from influencing candidate generation or reaching model context.

## Sequence
1. Require adapter capability contracts. 2. push policy into candidate generation. 3. govern identities, paths, and caches. 4. preserve denial semantics. 5. test alternate access paths.
