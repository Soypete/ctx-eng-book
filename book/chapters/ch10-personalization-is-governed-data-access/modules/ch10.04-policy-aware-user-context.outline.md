# Policy-Aware User Context

## Argument
Personal context is governed data access: purpose, interpretation, inference, retention, and disclosure—not read permission alone. Lexicon identifies authorized state, Semantics constrains its interpretation, and Pragmatics governs its use.

## Reliability goal
Prevent authorized data from being reused or persisted for an unauthorized purpose.

## Sequence
1. Separate access from use. 2. Map state, meaning, and use to Lexicon, Semantics, and Pragmatics. 3. Compile common decisions into store enforcement. 4. Govern inference and persistence; propagate lifecycle changes. 5. Test policy transitions.
