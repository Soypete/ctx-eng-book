# Policy-Aware User Context

## Argument
Personal context is governed by purpose, interpretation, inference, retention, and disclosure—not read permission alone.

## Reliability goal
Prevent authorized data from being reused or persisted for an unauthorized purpose.

## Sequence
1. Separate access from use. 2. compile common decisions into store enforcement. 3. govern inference and persistence. 4. propagate lifecycle changes. 5. test policy transitions.
