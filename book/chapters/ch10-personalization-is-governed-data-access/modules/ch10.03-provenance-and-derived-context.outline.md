# Provenance and Derived Context

## Argument
Provenance links source, authorization, transformation, inclusion, and derived descendants while preserving inherited restrictions.

## Reliability goal
Enable replay, correction, deletion, and failure diagnosis without treating lineage as proof or leaking sensitive audit data.

## Sequence
1. Define chain provenance. 2. inherit policy through derivation. 3. preserve a context-item record. 4. design protected replay/deletion. 5. evaluate lineage gaps.

## Example
Multi-parent derived context record.

Edited.
