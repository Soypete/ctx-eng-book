# Provenance and Derived Context

## Argument
Provenance links Lexicon source authority, Semantics transformations, Pragmatic authorization, inclusion, and derived descendants while preserving inherited restrictions.

## Reliability goal
Enable replay, correction, deletion, and failure diagnosis without treating lineage as proof or leaking sensitive audit data.

## Sequence
1. Define chain provenance across Lexicon, Semantics, and Pragmatics. 2. Inherit policy through derivation. 3. Preserve a context-item record. 4. Design protected replay/deletion. 5. Evaluate lineage gaps.

## Example
Multi-parent derived context record.
