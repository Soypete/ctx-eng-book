# Retrieval and Operation Evaluation

## Argument
Evaluate lexical coverage and authority, context admission, operation contracts, and effects separately before judging their composition across NLP systems.

## Beats
1. Define retrieval units, authority, and incomplete relevance sets.
2. Separate candidate retrieval, authority, final admission, model interpretation, and effects.
3. Treat pairwise and adaptive sampling signals as allocation aids, not verification.
4. Run oracle, no-retrieval, route, and reader ablations.
5. Test operation validation, authorization, idempotency, failure, and postconditions.
6. Progress from component tests to guarded production outcomes.
