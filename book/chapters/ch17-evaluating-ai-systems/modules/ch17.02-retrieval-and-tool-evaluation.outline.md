# Retrieval and Tool Evaluation

## Argument
Evaluate retrieval candidates, context admission, tool contracts, and effects separately before judging their composition.

## Beats
1. Define retrieval units and incomplete relevance sets.
2. Run oracle, no-retrieval, route, and reader ablations.
3. Test tool validation, authorization, idempotency, failure, and postconditions.
4. Progress from component tests to guarded production outcomes.
