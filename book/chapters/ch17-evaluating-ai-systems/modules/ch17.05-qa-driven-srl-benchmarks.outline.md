# QA-Driven Semantic-Role and Extraction Benchmarks

## Argument
QA-SRL, QAMR, and LSOIE provide inspectable linguistic representations, not universal production schemas.

## Beats
1. Distinguish each dataset and representation.
2. Evaluate questions, spans, and tuple conversion separately.
3. Avoid shared extractor/verifier errors.
4. Add domain semantics, grounding, and downstream evaluation.
