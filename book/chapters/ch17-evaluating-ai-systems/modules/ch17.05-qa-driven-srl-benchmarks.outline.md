# QA-Driven Semantic-Role and Extraction Benchmarks

## Argument
QA-SRL, QAMR, and LSOIE provide inspectable linguistic representations, not universal production schemas.

## Representation-to-evaluation flow

Mermaid flow from predicate-bearing text through questions, spans, predicate-argument structure, tuple evaluation, grounding, authority, and downstream checks.

## Beats
1. Distinguish each dataset and representation.
2. Evaluate questions, spans, and tuple conversion separately.
3. Keep stage boundaries and source offsets visible.
4. Avoid shared extractor/verifier errors.
5. Publish annotation and conversion rules with domain scores.
6. Add domain semantics, grounding, and downstream evaluation.
