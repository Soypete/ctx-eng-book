# Regression and Scenario Testing

## Argument
Regression tests compare context-to-outcome invariants and distributions rather than prose strings.

## Beats
1. Specify coverage, authority, semantics, state, dependencies, allowed variation, and outcome.
2. Pair baseline and candidate and repeat stochastic stages.
3. Convert incidents into minimal cases and nearby mutations.
4. Maintain stable and refreshed case sets.
