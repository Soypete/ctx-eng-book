# Tool Selection, Routing, and Validation

## Argument
Multi-step tool workflows require routing—model must decide sequence, pass outputs between calls, and know when complete. Tool routing is a pipeline problem with explicit exit criteria.

## Why it matters (reliability goal)
Routing turns pragmatic proposals into a governed sequence. It requires well-defined output schemas, identity and scope, provenance and freshness checks, authorization, completion criteria, and execution boundaries; these apply to workflows and pipelines as well as agents.
