# Tool Schemas and Function Calling

## Argument
Schemas define recognized input and output shapes. The host combines schema validation with semantic rules, authorization, idempotency, and audit to create an action boundary.

## Why it matters (reliability goal)
Schemas make the proposal legible, but reliable action contracts also expose purpose, meaning, identity, scope, provenance, freshness, and effects. The host combines representation checks with semantic validation and authorization to define the action boundary.
