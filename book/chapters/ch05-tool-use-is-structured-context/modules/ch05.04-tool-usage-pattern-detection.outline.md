# Tool Usage Pattern Detection

This module remains in Chapter 5 as the feedback path from structured tool traces to improved tool contracts. Chapter 16 owns telemetry mechanics; Chapter 17 owns experimental proof.

## Argument
Tool-call traces can be modeled as temporal events and analyzed for repeated sequences, failures, and cost. TwiCal is an analogy for event extraction, not evidence that the resulting patterns optimize language-system behavior.

## Why it matters (reliability goal)
Tool traces connect the Lexicon, Semantics, and Pragmatics questions over time: which sources and scopes were used, what identities and meanings were resolved, and which authorized effects followed. They enable bounded contract improvement for any language-system workflow, not only agents.

## Beats

1. **TwiCal as Inspiration** — evidence: ledger line 1115-1122, research/knowledge-graphs/07-informal-text-ie.md
   - TwiCal: extract (event, time, entity, context) from Twitter
   - For language workflows: extract (tool_call, sequence, task intent, identity/scope, context) from operational traces
   - Pattern: events + time = usage patterns

2. **Tool Usage as Event Extraction** — evidence: research notes
   - Detect when a tool is proposed, validated, authorized, or used → event detection
   - Track when it happens → temporal extraction
   - Build patterns over time → usage trends

3. **What This Enables** — evidence: research notes
   - Tool usage optimization: which tools frequently used together?
   - Problem pattern detection: what problems recur?
   - Contextual timing: when in conversation is something mentioned?
   - Trend analysis: tool X + problem Y = relationship for graph

4. **Graph Storage of Temporal Patterns** — evidence: research notes
   - Graph doesn't just store facts—it stores temporal usage patterns, provenance, and workflow state
   - Query patterns to test bounded contract changes, not to grant future authority

## Conclusion to reach
The reader should treat observed tool sequences as hypotheses for bounded contract and workflow changes, not as instructions or authority.
