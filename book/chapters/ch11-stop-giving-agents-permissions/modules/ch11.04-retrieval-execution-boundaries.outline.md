# Retrieval and Execution Boundaries

## Argument
Retrieval authority and execution authority are separate, purpose-bound grants;
consequential actions must be re-authorized against current state at commit.

## Reliability goal
Contain manipulated model proposals and TOCTOU changes without claiming one data-store check makes bypass impossible.

## Sequence
1. separate read and act and frame retrieval as evidence rather than authority. 2. reduce the candidate space with authorization before ranking. 3. distinguish scoped tool calls from dynamic access boundaries. 4. re-authorize protected fields at commit with a Mermaid flow. 5. bind grants to task and version. 6. cover every route. 7. test replay and TOCTOU.
