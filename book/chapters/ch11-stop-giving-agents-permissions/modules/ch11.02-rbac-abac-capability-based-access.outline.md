# RBAC, ABAC, Delegation, and Capabilities

## Argument
Authorization models compose across language and non-language systems. OAuth
delegates access, OpenID Connect authenticates to a client, and capabilities
carry authority only under explicit semantics.

## Reliability goal
Prevent protocol names, token formats, and broad scopes from being mistaken for least privilege.

## Primary sources
- [OAuth 2.0, RFC 6749](https://www.rfc-editor.org/rfc/rfc6749)
- [OpenID Connect Core 1.0](https://openid.net/specs/openid-connect-core-1_0.html)

## Sequence
1. Compose policy models. 2. explain OAuth delegation. 3. separate OIDC ID tokens. 4. define capability tradeoffs. 5. derive grants outside the model.
