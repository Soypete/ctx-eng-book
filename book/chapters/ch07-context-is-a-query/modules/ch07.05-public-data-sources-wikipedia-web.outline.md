# Public Data Sources: Wikipedia and the Web

## Argument

Public retrieval supplies background and current evidence, but search results, linked pages, and secondary citations must retain distinct authority and provenance through context assembly.

## Reliability goal

Use public sources without treating rank, snippets, hyperlinks, or retrieved instructions as truth or authority.

## Sequence

1. Establish public retrieval as a separate trust boundary.
2. Use search indexes for discovery and underlying pages for support.
3. Treat Wikipedia as a navigable secondary source with revision-aware provenance.
4. Correct the HATEOAS analogy and completeness assumptions.
5. Preserve authority when combining public and private context.
6. Evaluate claim support, source class, freshness, extraction, and injection resistance.

## Evidence

- [Wikibase Data Model](https://www.mediawiki.org/wiki/Wikibase/DataModel) — structured statements, qualifiers, references, and value precision.

## Examples

- Public regulation plus private plan state demonstrates independent authorities.
- “All cities” demonstrates why navigability does not guarantee completeness.
