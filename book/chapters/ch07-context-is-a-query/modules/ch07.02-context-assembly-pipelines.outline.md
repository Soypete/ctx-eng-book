# Context Assembly Pipelines

## Argument

A reliable context pipeline converts a scoped task into a typed retrieval plan and emits both bounded model context and an auditable assembly manifest.

## Reliability goal

Prevent missing, failed, stale, unauthorized, or oversized results from becoming indistinguishable prompt text.

## Sequence

1. Show why concatenation makes result order and string length into accidental policy.
2. Plan required, conditional, and optional retrieval from the task and host policy.
3. Represent `ok`, `empty`, `denied`, `stale`, `timeout`, `invalid`, and `error` outcomes.
4. Resolve authority, rank evidence, and allocate role-aware token budgets.
5. Emit model context plus an observable manifest and decision.
6. Test the assembler independently and with failure injection.

## Code example

Executable standard-library Python demonstrates typed source specifications, outcomes, and `proceed`/`degrade`/`stop` decisions. Production concerns are explicitly separated from the small teaching boundary.

## Substack shape

Standalone post and the principal implementation module for Chapter 7.
