# Pipes, Files, and Explicit Interfaces

## Argument
Context stages compose through typed, provenance-bearing envelopes; file and mount metaphors must preserve backend semantics and enforcement.

## Context engineering framework
- **Lexicon:** envelopes retain source, authority, provenance, freshness, and scope.
- **Semantics:** schemas and typed operations make meaning explicit across stages.
- **Pragmatics:** interfaces carry actor, purpose, authorization, failure, and effect constraints.

## Reliability goal
Prevent prose conversion and leaky universal APIs from erasing authority, freshness, errors, and cancellation.

## Example
Versioned context-item envelope and logical mount contract.
