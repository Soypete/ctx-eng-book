# Mounts, Namespaces, and Isolation

## Argument
Logical context namespaces organize state; real containment requires tested process, filesystem, network, identity, resource, and backend-policy boundaries.

## Context spine
- **Lexicon:** mounts expose only eligible, authoritative, provenance-bearing sources.
- **Semantics:** namespace entries describe typed views, operations, relationships, and consistency.
- **Pragmatics:** identity, purpose, policy, and effect boundaries govern access; infrastructure isolation supports but does not replace them.

## Reliability goal
Prevent naming conventions and workspace diagrams from being mistaken for tenant or execution isolation.

## Sequence
1. define logical namespace. 2. name real isolation. 3. contain resources/effects. 4. bound the process analogy. 5. penetration- and failure-test.
