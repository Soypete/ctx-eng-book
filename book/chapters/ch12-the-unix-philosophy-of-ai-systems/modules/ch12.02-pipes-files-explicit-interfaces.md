# ch12.02 Pipes, Files, and Explicit Interfaces

## Context Pipelines Need Typed Envelopes

UNIX pipes compose byte streams. Context pipelines need more than bytes because source, authority, authorization, freshness, and failure status affect how information may be used.

A stage envelope can carry:

```json
{
  "schema": "context-item/v2",
  "status": "ok",
  "source": "policy-service",
  "effective_at": "2026-08-06T12:00:00Z",
  "policy_decision": "authz-81",
  "payload": {"policy_id": "refund-v4"}
}
```

Retrieval, validation, ranking, assembly, and inference consume and produce versioned types. They must preserve cancellation, deadlines, errors, provenance, and backpressure. Converting everything to prose early destroys distinctions the host could enforce.

## File-Like Is an Analogy, Not a Universal API

Files offer stable naming and read/write semantics. A SQL snapshot, semantic search, graph traversal, and event subscription have different consistency, query, and authorization behavior. Hiding all of them behind `open(query)` can create a leaky abstraction.

Use a common envelope and lifecycle where helpful, while preserving typed operations such as `lookup`, `search`, `traverse`, and `subscribe`. Consumers should know the guarantees they depend on even if implementations remain replaceable.

## Progressive Disclosure Is Navigation Policy

Hierarchical indexes can let a workflow inspect a domain summary before loading full artifacts. That reduces blind context loading, but navigation still needs scope, loop and depth limits, freshness, provenance, and evaluation. A directory tree is not a semantic model or authorization system.

## Treat Mounted Context as a View

“Mounted state” is a useful mental model: a task receives a namespace of eligible sources. The mount table should record backend, operations, policy, consistency, lifecycle, and budget. It must not include secrets or imply that path permissions replace backend enforcement.

Test every stage independently and as a chain: malformed envelopes, schema skew, partial output, timeout, duplicate delivery, cancellation, and provenance loss. Measure contract violations, dropped metadata, queue depth, end-to-end latency, and replay equivalence.

The pipe analogy improves reliability when it produces small typed transformations with explicit failure semantics. The next module distinguishes a logical context namespace from actual process isolation.
