# Token and Context Economics

## Argument
Treat cost as a Lexicon-to-Semantics-to-Pragmatics pipeline property; optimize lifecycle cost per successful outcome, not token count in isolation. Treat the context window as an enforced admission boundary.

## Beats
1. Price terminal outcomes, recovery, and review.
2. Price ingestion, semantic processing, retrieval, model calls, state, latency, and review together with a Mermaid lifecycle flow.
3. Reserve output space and admit required evidence deterministically.
4. Separate context fit from context usefulness: position, cacheability, serving memory, and outcome quality.
5. Evaluate the marginal value of context on representative tasks.

## Reliability takeaway
Software owns context and spending budgets; smaller wins only when required outcomes hold.
