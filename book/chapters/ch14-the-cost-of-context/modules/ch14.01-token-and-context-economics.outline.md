# Token and Context Economics

## Argument
Optimize lifecycle cost per successful outcome, not token count in isolation. Treat the context window as an enforced admission boundary.

## Beats
1. Price terminal outcomes, recovery, and review.
2. Reserve output space and admit required evidence deterministically.
3. Evaluate the marginal value of context on representative tasks.

## Reliability takeaway
Software owns context and spending budgets; smaller wins only when required outcomes hold.
