# Retrieval, Tool, and Latency Costs

## Argument
Retrieval and tools consume lifecycle cost and the task's end-to-end deadline.

## Beats
1. Trace and budget the critical path and tail latency.
2. Price retrieval from ingestion through canonical fetch.
3. Include retries, recovery, and expected side-effect loss in tool cost.

## Reliability takeaway
Optimize latency and cost without deleting evidence required for a safe outcome.
