# NER and LLM Extraction Costs

## Argument
Compare extraction methods only against the same assertion contract, distribution, and lifecycle horizon.

## Beats
1. Distinguish NER from broader information extraction.
2. Price development, operation, review, error, and maintenance.
3. Evaluate the same contract and important slices.
4. Account for schema and distribution change.

## Reliability takeaway
There is no universal break-even volume; earn the choice on production data.
