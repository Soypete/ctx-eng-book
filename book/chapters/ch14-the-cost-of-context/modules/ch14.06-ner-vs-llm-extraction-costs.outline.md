# NER and LLM Extraction Costs

## Argument
Compare extraction methods only against the same assertion contract, distribution, and lifecycle horizon.

## Beats
1. Distinguish NER from broader information extraction.
2. Price development, operation, review, error, and maintenance with a lifecycle flow.
3. Treat accepted assertions, not raw calls, as the cost unit.
4. Evaluate the same contract and important slices, including confidence and review routing.
5. Account for schema and distribution change.

## Reliability takeaway
There is no universal break-even volume; earn the choice on production data.
