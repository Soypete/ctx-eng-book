# Local Models and Model Routing

## Argument
Local and API deployments have different lifecycle costs; routing is reliable only with observable acceptance and eligibility policy.

## Beats
1. Compare total cost per success under representative load.
2. Evaluate capability and quantization by task slice rather than model category.
3. Route only after eligibility and residency checks, then test cascades, escalation, shift, and routing regret with a Mermaid flow.

## Reliability takeaway
Choose routes that satisfy outcome, security, and latency constraints at the lowest expected lifecycle cost.
