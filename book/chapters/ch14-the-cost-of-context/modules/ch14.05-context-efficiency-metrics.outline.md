# Context Efficiency Beyond Token Cost

## Argument
Context efficiency is constrained multi-objective comparison, not a universal scalar.

## Beats
1. Define success and hard constraints before resources, then map them to a Mermaid frontier flow.
2. Trace the full resource vector against terminal outcomes.
3. Compare nondominated policies on a practical Pareto frontier without collapsing hard constraints into one score.
4. Optimize only against held-out, failure-aware evaluation.

## Reliability takeaway
Select the lowest-cost nondominated design that satisfies hard task constraints.
