# Diagnosing Model Problems

## Argument
Model modification is the residual decision: it requires evidence that a valuable, stable failure remains after Lexicon, Semantics, Pragmatics, retrieval, authorization, orchestration, and evaluation have been tested.

## Beats
1. Define and reproduce the failure with a complete run manifest.
2. Test the context spine and its enforcement boundaries one at a time.
3. Separate fresh knowledge, stable behavior, capability, and enforcement.
4. Record an escalation matrix, regression plan, and rollback.

## Reliability takeaway
Context engineering is the broader research discipline; it produces the diagnosis and contract that any model intervention requires.
