# Diagnosing Model Problems

## Argument
Model modification requires evidence that a valuable, stable failure remains after controlled context, interface, tool, workflow, evaluator, and model ablations.

## Beats
1. Define and reproduce the failure with a complete run manifest.
2. Change one system boundary at a time.
3. Separate fresh knowledge, stable behavior, capability, and enforcement.
4. Record an escalation matrix, regression plan, and rollback.

## Reliability takeaway
Context engineering is research because it produces the diagnosis and contract training requires.
