# Distillation and Specialized Models

## Argument
Distillation, small models, and specialized components reshape the capability-cost envelope; none is a universal upgrade or downgrade.

## Beats
1. Distill a defined behavior and audit teacher-derived data and provenance.
2. Benchmark the complete student and teacher workflows with a fallback boundary.
3. Treat size as one deployment property among many.
4. Specialize the narrowest component that fixes the diagnosed failure.
5. Promote only with versioned release evidence and slice results.

## Reliability takeaway
Compare all candidates against the same production system contract.
