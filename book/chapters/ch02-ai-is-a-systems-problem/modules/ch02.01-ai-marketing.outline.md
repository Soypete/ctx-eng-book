# Context Infrastructure Is the System

## Argument
“AI” obscures component boundaries. Reliable language systems require engineered data, state, retrieval, semantics, authorization, orchestration, and evaluation around whichever model or NLP component is used.

## Why it matters (reliability goal)
Use the Lexicon → Semantics → Pragmatics spine: identify sources and authority, make meaning explicit, and constrain the permitted use of outputs.

## Beats

1. **The Label Hides the Work** — evidence: existing prose
   - “AI” spans models, products, workflows, and infrastructure
   - Ambiguity makes distinct failure boundaries look alike

2. **A Model-Agnostic Discipline** — evidence: existing prose
   - Model quality remains task-, cost-, and deployment-dependent
   - The surrounding context and control plane survives model changes

3. **Lexicon → Semantics → Pragmatics** — evidence: chapters.md and research note
   - A non-agent classifier still needs authoritative data, explicit meaning, and constrained outputs
   - Prompt wording is one replaceable interface

## Conclusion to reach
The reader should treat prompt wording as one replaceable interface and invest in system knowledge encoded in retrieval, state, authorization, operations, and evaluation.
