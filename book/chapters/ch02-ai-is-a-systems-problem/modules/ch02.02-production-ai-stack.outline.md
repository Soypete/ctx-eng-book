# The Production Context Stack

## Argument
The model or NLP component sits inside a stack of hardware, execution, data, semantics, orchestration, and governance. Production reliability emerges from contracts across the complete context-to-outcome path.

## Why it matters (reliability goal)
Use the context engineering framework: sources and authority become meaning, then constrained outcomes. Model capability ≠ production reliability.
